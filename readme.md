### 📝 Todo List

Simple and lightweight **Todo List Tracker** built to help you organize daily tasks

---

#### 🚀 Features
- Add task with dates
- Cross off if task mark as complete
- Delete button to remove task from tracker 

---

### ⚙️ How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Mecha-Coder/Simple-Todo-List
   ```
2. Navigate to the Calculator folder
3. Open the `index.html` file in your browser
